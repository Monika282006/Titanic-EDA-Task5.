# Titanic Dataset – Exploratory Data Analysis (EDA)

## Task 5 – Exploratory Data Analysis

### Objective
To extract meaningful insights from the Titanic dataset using statistical analysis and data visualization.

### Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

### Analysis Performed
- Dataset description using `.describe()`
- Dataset information using `.info()`
- Frequency analysis using `.value_counts()`
- Missing-value analysis
- Age distribution histogram
- Age boxplot
- Age vs Fare scatterplot
- Correlation heatmap
- Pairplot
- Survival analysis by gender
- Survival analysis by passenger class
- Survival analysis by embarkation port

### Key Findings
- Female passengers had a higher survival rate than male passengers.
- Passenger class had an important relationship with survival.
- First-class passengers generally had better survival outcomes.
- Higher fare values were generally associated with better survival outcomes.
- Age and fare showed no strong direct relationship.
- The analysis revealed important patterns in passenger survival.

### Files
- `Titanic_EDA_Task5.ipynb` – Jupyter Notebook containing the complete EDA.
- `Titanic_EDA_Task5_Report.pdf` – PDF report containing the analysis and findings.

## Conclusion
The exploratory data analysis helped identify important relationships and trends in the Titanic dataset. Gender, passenger class, and fare were among the major factors associated with passenger survival.
